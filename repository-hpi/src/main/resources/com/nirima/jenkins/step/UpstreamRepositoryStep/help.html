Configures the upstream repository by defining JENKINS_REPOSITORY (and Jenkins.Repository for backwards compatibility) in the Maven environment.
The recommended way of using this is to create a profile in the Jenkins settings.xml: 
        <profile>
            <id>jenkins-maven-upstream</id>
            <activation>
                <property>
                    <name>env.JENKINS_REPOSITORY</name>
                </property>
            </activation>
            <repositories>
                <repository>
                    <id>jenkins</id>
                    <url>${env.JENKINS_REPOSITORY}</url>
                    <releases>
                        <enabled>true</enabled>
                    </releases>
                    <snapshots>
                        <enabled>true</enabled>
                    </snapshots>
                </repository>
            </repositories>
            <pluginRepositories>
                <pluginRepository>
                    <id>jenkins</id>
                    <url>${env.JENKINS_REPOSITORY}</url>
                    <releases>
                        <enabled>true</enabled>
                    </releases>
                    <snapshots>
                        <enabled>true</enabled>
                    </snapshots>
                </pluginRepository>
            </pluginRepositories>
        </profile>

This profile is automatically enabled when the step selects an upstream repository.
Execute the step before any Maven steps. For pipeline jobs, use the Pipeline Maven Integration Plugin's withMaven { ... } step so Maven artifacts are available as an upstream repository.
